# Social Media Platform

## About the Project
This is a simple Social Media Platform developed using HTML, CSS, and JavaScript. It allows users to interact with a user-friendly interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- User-friendly interface
- Responsive design
- Create and view posts
- Like and comment features
- Dark and Light mode
- Local Storage support
